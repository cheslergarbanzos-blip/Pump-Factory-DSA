================================================================
 PUMP FACTORY WEBSITE
================================================================

OVERVIEW
--------
Pump Factory is a bouldering, fitness, and yoga gym located in
Juntado Subdivision, 3rd St, Molo, Iloilo City, 5000 Philippines.
This project is a multi-page static website built with HTML and
CSS (with small amounts of vanilla JavaScript) that introduces
visitors to the gym, its services, pricing, gallery, and contact
information.

PAGES
-----
pump_factory/Home.html
    Landing page with a welcome introduction, First Time Pass
    call-to-action, FAQ, safety and equipment info, opening hours,
    location, and upcoming/previous events.

pump_factory/About_us.html
    Business background/history, mission, vision, and values, and
    an overview of what the gym offers.

pump_factory/Services.html
    Full list of services offered (Climbing, Fitness Center, Yoga
    Classes, Personal Training, Kids Climbing Program, Route
    Setting Workshops), the First Time Pass details, and a price
    list section.

pump_factory/Gallery.html
    Photo gallery of the gym, climbers, and events, plus a link to
    an external Google Drive album for past events.

pump_factory/Contact_us.html
    Contact form (name, email, phone, reason, preferred contact
    method, message, newsletter opt-in), plus quick-contact cards
    (email, location/Google Maps, Instagram, Facebook) and
    operating hours.

FOLDER STRUCTURE
----------------
img/
    bg/        Background images used by section headers
    emoji/     Icon images used for the services list
    gallery/   Photos used on the Gallery page
    icons/     Logo and small UI icons (email, location, social)
    services/  Images used on the Services page (passes, pricing)

pump_factory/
    Home.html, About_us.html, Services.html, Gallery.html,
    Contact_us.html - the site's pages

style/
    styles.css   Shared styles (navbar, sidebar, footer, base rules)
    home.css     Styles specific to Home.html
    about.css    Styles specific to About_us.html
    services.css Styles specific to Services.html
    gallery.css  Styles specific to Gallery.html
    contact.css  Styles specific to Contact_us.html

FEATURES
--------
- Responsive navbar with a collapsible hamburger sidebar on every page
- Consistent site footer with quick links and social/contact links
- Contact form demonstrating multiple HTML form controls (text,
  email, tel, select, radio, checkbox, textarea) that composes a
  pre-filled email via a mailto: link on submit
- Clickable social links (Facebook, Instagram) and a Google Maps
  link for the gym's location
- Image gallery with consistent sizing
- Upcoming/previous events lists on the Home page

TECHNOLOGIES USED
------------------
- HTML5
- CSS3 (Flexbox and Grid layouts)
- Vanilla JavaScript (sidebar toggle, contact form submission)

HOW TO VIEW
-----------
Open pump_factory/Home.html in a web browser to start browsing the
site. All pages link to each other through the navbar, sidebar,
and footer.
